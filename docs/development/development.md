# :material-handshake: Contribution Guidelines

This page provides guidelines on how to contribute to your resporistories. We highly appreciate your contributions!

## :material-github: Our contribution platform

We uses [:material-github: GitHub](https://github.com/ricky074game) to manage everything.

<!-- --8<-- [end:gitNotice] -->

## :octicons-git-commit-24: Areas of contribution

A Code of Conduct applies to each repository. Please read it before contributing.

### RevoltUltimate

[:simple-github: GitHub Repository](https://github.com/ricky074game/RevoltUltimate){ .md-button }

[:material-license: License (MIT)](https://github.com/ricky074game/RevoltUltimate/blob/master/LICENSE){ .md-button }

[:material-tag: Releases](https://github.com/ricky074game/RevoltUltimate/releases){ .md-button }

A modern .NET program to track achievements and provide real-time updates with custom notifications from multiple platforms. It recreates the console feel of unlocking achievements.

See the [RevoltUltimate contribution guide](RevoltUltimate.md) on how to get started.

### Revolt Documentation

[:simple-github: GitHub Repository](https://github.com/ricky074game/RevoltDocs){ .md-button }

The website that you are looking at. We made the Revolt documentation in [MkDocs Material](https://squidfunk.github.io/mkdocs-material/), a documentation framework that uses markdown.

### Revolt Toasts

You can make your own achievements to be used by other people in RevoltUltimate! This is probably the best way to contribute to RevoltUltimate if you so want to.

Please follow the [Toasts Guide](toasts.md) in order to get started and how to submit it.

### Revolt Achievement

[:simple-github: GitHub Repository](https://github.com/ricky074game/RevoltAchievement){ .md-button }

This repository contains the achievement data for RevoltUltimate. This is the easiest way to contribute and requires no coding knowledge to do so!

See the [Revolt Achievement contribution guide](RevoltAchievement/RevoltAchievement.md) on how to get started.

## :octicons-git-pull-request-24: How to make changes

1: Make a fork of this repristory

2: Submit a pull request with the description and I will give you feedback

## :material-format-letter-case: Formatting

Before a pull request, ensure that:

- Your changes comply with the general formatting of a repository

- There's a minimal amount of mistakes; check grammar and anything else important
