    Contribution Guidelines¶

    This page provides guidelines on how to contribute to your resporistories. We highly appreciate your contributions!

    Our contribution platform¶

    We uses GitHub to manage everything.

    Areas of contribution¶

    A Code of Conduct applies to each repository. Please read it before contributing.

    RevoltUltimate¶

    GitHub Repository

    License (MIT)

    Releases

    A modern .NET program to track achievements and provide real-time updates with custom notifications from multiple platforms. It recreates the console feel of unlocking achievements.

    See the RevoltUltimate contribution guide on how to get started.

    Revolt Documentation¶

    GitHub Repository

    The website that you are looking at. We made the Revolt documentation in MkDocs Material, a documentation framework that uses markdown.

    Revolt Toasts¶

    You can make your own achievements to be used by other people in RevoltUltimate! This is probably the best way to contribute to RevoltUltimate if you so want to.

    Please follow the Toasts Guide in order to get started and how to submit it.

    Revolt Achievement¶

    GitHub Repository

    This repository contains the achievement data for RevoltUltimate. This is the easiest way to contribute and requires no coding knowledge to do so!

    See the Revolt Achievement contribution guide on how to get started.

    How to make changes¶

    1: Make a fork of this repristory

    2: Submit a pull request with the description and I will give you feedback

    Formatting¶

    Before a pull request, ensure that:

    • Your changes comply with the general formatting of a repository

    • There's a minimal amount of mistakes; check grammar and anything else important
